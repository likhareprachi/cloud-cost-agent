📖 How to Operate the Cloud Cost Agent Platform

A detailed guide on utilizing autonomous cost audits, interactive filters, and the Llama 3 Cost CoPilot.

01

Trigger Billing Scans

Click the glowing "Run Agent Now" button in the header to animate a simulated scan, or execute python backend/agent.py in your VS Code terminal to fetch live AWS configurations and compile Llama 3 audits to Firestore.

02

Apply Decommission Actions

Review waste findings in the Immediate Waste Mitigation checklist. Toggle checkboxes next to items to resolve them. Your active spend metrics, waste percentages, and SVG distribution charts will recalculate instantly.

03

Consult Llama 3 CoPilot

Ask the sidebar Groq Cost CoPilot chat assistant detailed questions. Type custom prompts like "Explain S3 spike" or click the suggestion chips to receive database downsizing and staging server remediation timelines.

🎛️ Environment Scope: Use the top tabs to isolate Production, Staging, or Development assets dynamically.
📤 Export Reports: Click "Export JSON Report" to download offline ledger profiles of your active environment configuration.
